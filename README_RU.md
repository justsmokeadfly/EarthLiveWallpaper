EarthLive Wallpaper автоматически получает самый свежий доступный снимок Himawari, собирает его в полноценное изображение Земли и устанавливает как обои Windows.

## 🛠️ Исправлено в v1.8.4

- Исправлено неработающее Ctrl+C/V/X/A в любых текстовых полях (Настройки, поиск по фото) при не-латинской раскладке клавиатуры (например, русской) — известный баг Tk/Windows, где эти сочетания привязаны к символу клавиши, а не к самой физической клавише.
- Добавлена настройка «API-ключ NASA» (необязательно, хранится только локально) — можно использовать свой бесплатный ключ с [api.nasa.gov](https://api.nasa.gov/) (1000 запросов/час) вместо общего `DEMO_KEY` (30/час).
- В каждой карточке фото в галереях NASA/Уэбб/Хаббл добавлены кликабельные ссылки — можно открыть само изображение или страницу-источник в браузере.

## 🛠️ Исправлено в v1.8.3

- NASA APOD теперь показывает понятное сообщение, если общий демо-ключ `DEMO_KEY` упирается в лимит (30 запросов/час, разделяется вообще всеми приложениями в мире), вместо сырой HTTP-ошибки. Уменьшено окно отката по дням при видео-APOD, чтобы не жечь общую квоту так быстро.
- Теперь в браузере фото NASA/Уэбба/Хаббла показывается разрешение каждого снимка (для Уэбба/Хаббла — из метаданных ленты Flickr, для APOD — из уже скачанного изображения, без лишних загрузок).
- Важно: `DEMO_KEY` в принципе ограничен и общий для всех. Для надёжной загрузки APOD стоит завести бесплатный личный ключ на [api.nasa.gov](https://api.nasa.gov/) (выдаётся мгновенно, лимит 1000 запросов/час) — его можно будет вписать в приложение.

## 🛠️ Исправлено в v1.8.2

- Исправлена ошибка «Failed to load Flickr webb/hubble feed» — в ссылках на ленты Уэбба и Хаббла в параметре `nsid` использовался текстовый юзернейм аккаунта вместо числового ID, который на самом деле требует API Flickr.
- Исправлено падение NASA APOD с ошибкой «did not return an image» в дни, когда NASA публикует видео вместо фото (например, кадры запуска) — теперь приложение автоматически берёт последний день, для которого есть изображение.

## 🔒 Обновление безопасности в v1.8.1

- Обновлена библиотека `Pillow` с `10.3–10.x` до `12.3+` — устранены несколько опубликованных уязвимостей (проблемы с безопасностью памяти и отказом в обслуживании при обработке недоверенных изображений).
- Исправлена необработанная ошибка `comtypes.COMError` в коде установки обоев на разные мониторы, которая раньше могла приводить к падению вместо корректной обработки сбоя.

## 🖼️ Режимы установки обоев

Для фотографий NASA, James Webb и Hubble доступны:

- **Заполнить (Fill)** — заполнить экран, при необходимости обрезав края.
- **Вписать (Fit)** — показать всё изображение без обрезки.
- **Растянуть (Stretch)** — растянуть изображение на экран.
- **Замостить (Tile)** — повторять изображение.
- **По центру (Center)** — оставить исходный размер и расположить по центру.
- **На все мониторы (Span)** — растянуть на все мониторы.
